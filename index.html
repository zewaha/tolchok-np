Обновлённая политика конфиденциальности

Чтобы продолжить пользоваться Толкан, необходимо ознакомиться с информацией и подтвердить согласие.

Какие данные обрабатываются

  • Никнейм и идентификатор аккаунта.
  • Отзывы, оценки, комментарии и добавленные места.
  • Реакции, жалобы и данные, необходимые для модерации.
  • Технические сведения, необходимые для авторизации и защиты сайта.

Где хранятся данные

Для базы данных и авторизации используется Supabase. Основной регион проекта Supabase — Ирландия. Это не означает, что абсолютно все технические сведения и служебные данные обрабатываются исключительно в этой стране.

Сторонние сервисы

Для защиты форм используется Cloudflare Turnstile. Для отображения карт и определения адресов используются OpenStreetMap и Nominatim.

Публичная информация

Никнейм, отзывы, оценки и добавленные места могут быть видны другим посетителям сайта. Не публикуй в отзывах домашний адрес, номер телефона, настоящее имя, название своей школы или другие личные сведения.

Важно

Не используй сайт для публикации чужих личных данных. Если ты не согласен с обработкой данных на описанных условиях, не продолжай пользоваться аккаунтом.
